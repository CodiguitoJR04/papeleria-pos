# Papelería POS

Sistema de punto de venta para papelería, desarrollado en JavaFX.

## Características

- Punto de venta (POS) con escáner de código de barras
- Inventario (productos, categorías, proveedores)
- Facturación (CFDI 4.0)
- Control de turnos y caja
- Impresión de tickets en impresora térmica (ESC/POS)
- Reportes de ventas

## Requisitos

- **Java 21** o superior
- **MySQL 8** o superior
- Windows, macOS o Linux
